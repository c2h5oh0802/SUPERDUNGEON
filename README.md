# 沉眠之心 · SUPERDUNGEON

第一人稱慢動作地城潛入原型（桌面瀏覽器、鍵盤＋滑鼠）。

> 潛入一座沉睡的地城，用慢動作讀懂每一個危險，決定要潛行、繞路還是出手；拿走「沉眠之心」後整座地城甦醒，你得活著把它帶出去。

技術：TypeScript 5.9、Three.js 0.180、Vite 7.3（依賴版本鎖定在 `package-lock.json`）。美術、音效全部程序生成，執行時不從外站載入任何資源。

---

## 快速開始

需要 Node.js 20 以上。

```bash
npm ci
npm run dev        # http://127.0.0.1:5173/
```

打包成靜態網站：

```bash
npm run build      # 輸出到 dist/（base 為相對路徑，可放在任意子路徑）
npm run preview    # http://127.0.0.1:4173/ 預覽打包結果
```

`dist/` 可以直接放到任何靜態主機（GitHub Pages、Netlify、S3、Nginx…）。
不支援直接雙擊 `index.html` 以 `file://` 開啟（瀏覽器會擋 ES 模組）。

## 玩法

**目標**：從入口石階深入地城，在最深處取走**沉眠之心**，再帶著它回到**入口石階**按 E 離開。不需要殺光敵人。

**地城甦醒**：取心的瞬間，所有睡著的敵人醒來、視野變廣、發現你的速度變快，離心核房近的敵人會前往查看。進去時留下的每個敵人，都會在出來時變成你的問題。

### 時間規則（單一模式：慢動作）

| 狀態 | 世界流速 |
|---|---|
| 靜止、觀察、瞄準 | 0.1 倍（慢動作） |
| 移動 | 走多遠、世界就前進多少（全速行走＝正常速度） |
| 攻擊、投擲、喝藥、開門、互動 | 以該行動所需時間、正常速度播放；行動中可移動但不能取消或重疊 |
| 按住空白鍵 | 正常速度 |
| 暫停、地圖、刻印選擇 | 完全停止 |

同時移動與行動時取最大值、不加總，世界速度永遠不超過正常速度。

### 行動時間（世界秒）

| 行動 | 時間 | 效果 |
|---|---|---|
| 劍（1） | 0.6（準備 0.15／作用 0.12／恢復 0.33） | 4 傷；對未察覺的敵人背刺 ×3；作用開始時鎖定揮擊方向 |
| 弩（2） | 0.8（含上弦） | 實體箭 40 m/s；身體 3、頭部 6；射進牆的箭可以撿回 |
| 投石（3） | 0.3 | 1 傷（頭 2）；落點發出聲響，引開未察覺的敵人 |
| 煙霧瓶（Q） | 0.4 | 高拋、落地或被擊中破裂；10 秒煙霧擋住視線、不擋路、不刪除已射出的箭 |
| 喝藥（H） | 0.8 | 行動結束時 +4 生命 |
| 開關門（E） | 0.3 | 門口有人時拒絕關門 |
| 寶箱、祭壇、取心、離開（E） | 0.6 | — |

**空中擊破**：箭或石頭在空中打中飛行中的煙霧瓶，瓶子在那個位置破裂，效果與落地相同（不是必要操作）。

### 敵人

| 敵人 | 看點 | 對策 |
|---|---|---|
| 盾衛（寬肩、圓盾、闊劍） | 舉劍發光 → 揮擊方向鎖定 | 側移或後退；正面盾牌擋箭，瞄頭或繞背 |
| 弩手（兜帽、長弩） | 紅色瞄準線，變亮代表已鎖定 | 側移閃弩矢；任何命中都會打斷瞄準 |
| 突進者（角盔、衝撞盾） | 低頭蓄勢，地上出現橘色衝鋒線 | 閃開讓它撞牆：暈眩 1.5 秒、受傷 ×2 |

敵人頭上：**Zz** 睡眠、**?** 起疑（圈填滿就會發現你）、**!** 發現你。敵人會開門，但要停下來花時間。

### 刻印（兩座祭壇、各二選一，本局有效）

穿甲（弩箭穿透 1 名敵人）、疾刃（揮劍 0.6 → 0.42 秒）、影行（被發現所需時間 +60%）、堅韌（最大生命 +4 並回復 4）。說明文字由參數自動生成，並有測試確認效果一致。

### 操作

| 按鍵 | 功能 |
|---|---|
| WASD | 移動 |
| 滑鼠 | 觀察／瞄準 |
| 左鍵 | 使用目前工具（按住可連續） |
| 1 / 2 / 3 | 劍／弩／投石（不會取消進行中的行動） |
| Q | 投煙霧瓶 |
| E | 互動（門、寶箱、祭壇、沉眠之心、出口） |
| H | 喝藥 |
| 空白（按住） | 等待：讓時間正常流動 |
| Tab 或 M | 地圖（世界暫停） |
| Esc | 暫停 |
| 右鍵拖曳／方向鍵 | 無法鎖定滑鼠時（例如受限 iframe）的備用轉視角 |

按鍵以實體鍵位判斷，開著中文輸入法也能操作。

### 種子與地城

- 主選單可輸入種子；留空則隨機產生 6 字元種子。結算畫面可「同種子再試」或換新種子。
- 同一個種子會重建完全相同的初始地城與內容。
- 地城由 **2 個手工拓撲模板**（「環形中庭」有可繞行的環線；「分岔長廊」有危險支線與只能從內側拉開門閂的捷徑）加上鏡像，再從 **13 個手工設計的房間佈局**（另有 2 個練習場佈局）中挑選組合；敵人位置與配置是設計好的，依房間深度增減。這是「模板＋組合」，不是任意程序生成。
- 生成器保證：入口房沒有敵人、出生點附近看不到敵人、不經過陷阱與單向門也能抵達沉眠之心、所有寶箱與祭壇可達（以角色半徑擴張後的導航格檢查）。

### 操作練習

主選單「操作練習」：一個固定的小場地，使用與正式冒險相同的系統，有睡著的盾衛（練背刺）、巡邏盾衛、高台弩手、突進者與踏板陷阱；補給台（E）可補滿物資，暫停選單可重置。

## 測試

```bash
npm run typecheck   # TypeScript strict
npm run lint        # ESLint
npm test            # Vitest：時間規則、戰鬥、空爆、感知、AI、生成、完整流程（56 項）
npm run build
```

瀏覽器端腳本（需先 `npm run dev` 或 `npm run preview`，並設定 `BASE_URL`，預設 `http://127.0.0.1:5173/`）：

```bash
node e2e/browser.mjs      # 主選單、localStorage 封鎖、失焦／分頁／Esc 暫停、縮放、受限 iframe、觸控提示、連續重開不殘留
node e2e/airburst.mjs     # 練習場：以正常動作鏈（Q 投瓶 → 3 → 瞄準 → 左鍵）空中擊破煙霧瓶
node e2e/retry.mjs        # 死亡 → 結算 → 同種子重試（佈局相同）→ 新種子（佈局不同）
node e2e/playthrough.mjs RUN1   # 以正常鍵鼠操作嘗試完成一整局
```

自動化腳本使用正常操作輸入（WASD、方向鍵轉向、滑鼠左鍵、E/Q/H/空白），但會透過開發模式讀取狀態來決定路線與瞄準，屬於「狀態讀取輔助」，不等同真人操作。

### 開發模式

網址加上 `?dev=1` 會掛上 `window.__sd`：讀取時間、玩家、敵人、投射物、煙霧、種子與關鍵事件（`state()`、`level()`、`events()`、`renderInfo()`、`loops()` 等）。`__sd.debug.*` 是狀態注入（傳送、設定視角、設定生命），只用於定位問題。正式遊玩不會顯示任何作弊功能。

`?gfx=low` 關閉抗鋸齒並降低解析度，用於無 GPU 的自動化環境。

## 專案結構

```
src/config.ts          所有可調參數（刻印說明文字由此生成）
src/core/              時間規則（computeWorldDt）、唯一渲染迴圈、種子 PRNG、數學
src/sim/               純 TypeScript 世界模擬（不依賴渲染，可在 Node 測試）
  grid.ts nav.ts       1 m 碰撞格、3D 視線、0.5 m 導航格＋A*
  playerSys.ts         移動、行動系統、劍、投射物出手、互動
  projectileSys.ts     箭／弩矢／石／瓶的掃掠碰撞、同時空交會（空爆）
  enemySys.ts          感知（睡眠／未察覺／警戒／搜索、發現量表、噪音）與三種敵人行為
  propSys.ts           門、陷阱、煙霧、掉落物
src/gen/               手工房間佈局、拓撲模板、生成器與驗證
src/render/            烘焙頂點光的關卡網格、角色、第一人稱、特效、材質
src/ui/ src/input/ src/audio/ src/dev/
tests/                 Vitest
e2e/                   Playwright 腳本
```

## 已知限制

- 這是原型：數值（慢動作 0.1、行動時間、敵人強度、甦醒強度）都是第一版，尚未經過人工試玩調整。
- 只有單層地城、2 個拓撲模板、13 個房間佈局；重玩變化來自組合與鏡像。
- 沒有手機觸控操作與手把支援（觸控裝置會顯示提示）。
- 音效為程序合成，只做過「無錯誤、會建立音訊節點」的檢查，未經人耳調整。
- 在沒有 GPU 的環境（軟體渲染）幀率很低；一般桌面 GPU 的實際幀率尚未量測。
- `vitest` 3.x 仍有一則中度安全公告（測試工具的 mock 重新導向功能，本專案未使用、不影響打包結果）。

## 與原需求的差異（經討論後調整）

- 取消「完全停時」模式，只保留慢動作。
- 加入輕量潛入（睡眠、發現量表、噪音、背刺）；投石改為「製造聲響誘敵」。
- 出口改為入口石階；取心後觸發「地城甦醒」。
- 局內強化改名為「刻印」；敵人會開門（需要時間）；射出的箭可撿回。
- 拓撲模板 2 個（原為 2–3 個），空爆不設專屬房間。
