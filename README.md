# 沉眠之心 · SUPERDUNGEON

第一人稱慢動作地城潛入原型（桌面瀏覽器、鍵盤＋滑鼠）。

> 潛入一座沉睡的地城，用慢動作讀懂每一個危險，決定要潛行、繞路還是出手；一層一層往下，在最底層取得「沉眠之心」。

技術：TypeScript 5.9、Three.js 0.180、Vite 7.3（依賴版本鎖定在 `package-lock.json`）。美術、音效全部程序生成，執行時不從外站載入任何資源。

---

## 快速開始

需要 Node.js 20 以上。

```bash
npm ci
npm run dev        # http://127.0.0.1:5173/
```

打包成靜態網站：

```bash
npm run build      # 輸出到 dist/（base 為相對路徑，可放在任意子路徑）
npm run preview    # http://127.0.0.1:4173/ 預覽打包結果
```

`dist/` 可以直接放到任何靜態主機（GitHub Pages、Netlify、S3、Nginx…）。
不支援直接雙擊 `index.html` 以 `file://` 開啟（瀏覽器會擋 ES 模組）。

## 玩法

**目標**：地城共 **4 層**。每一層找到**往下的階梯**（石拱門、青色光錐），在第 4 層取得**沉眠之心**就通關。不需要殺光敵人；來時的階梯回不去。

**逐層往下**：
- 同一個種子決定整局 4 層的地形與敵人。
- 越深，房間裡的敵人越多、醒著的越多；第 4 層是暫代的首領房：沉眠之心旁有盾衛與突進者守著。
- 生命、物資、藥劑箭、刻印與統計都會帶到下一層。
- **每層開頭自動存檔**。關掉網頁再回來，主選單會出現「繼續：第 N 層」；死亡或通關時清除存檔。存檔被瀏覽器封鎖時照常遊玩，只是不能續玩。

（原本「取心後地城甦醒、帶心回入口」的撤離段，這一輪先拿掉；甦醒度之後會改成跨層的長期壓力，見 `docs/vertical-slice.md`。）

### 時間規則（單一模式：慢動作）

| 狀態 | 世界流速 |
|---|---|
| 靜止、觀察、瞄準 | 0.1 倍（慢動作） |
| 移動 | 走多遠、世界就前進多少（全速行走＝正常速度） |
| 攻擊、投擲、喝藥、開門、互動 | 以該行動所需時間、正常速度播放；行動中可移動但不能取消或重疊 |
| 按住空白鍵 | 正常速度 |
| 暫停、地圖、刻印選擇 | 完全停止 |

同時移動與行動時取最大值、不加總，世界速度永遠不超過正常速度。

### 行動時間（世界秒）

| 行動 | 時間 | 效果 |
|---|---|---|
| 長劍（戰士 1） | 0.6（準備 0.15／作用 0.12／恢復 0.33） | 4 傷；對未察覺的敵人背刺 ×3；作用開始時鎖定揮擊方向 |
| 獵刀（獵手 1） | 0.4 | 3 傷；背刺 ×3（9，一擊背刺盾衛） |
| 獵弓（獵手 2）、藥劑箭（獵手 3） | 0.8（含拉弓） | 實體箭 40 m/s；身體 3、頭部 6；射進牆的箭可以撿回；藥劑箭另外麻痺或冰寒 |
| 投擲石（戰士 2） | 0.3 | 1 傷（頭 2）；落點發出聲響，引開未察覺的敵人；有限、落地可撿回 |
| 臂盾・盾推（戰士，右鍵／F） | 0.4 | 擋下正面攻擊與弩矢，把身前的敵人推退 2 m |
| 煙霧瓶（Q） | 0.4 | 高拋、落地或被擊中破裂；10 秒煙霧擋住視線、不擋路、不刪除已射出的箭 |
| 喝藥（H） | 0.8 | 行動結束時 +4 生命 |
| 開關門（E） | 0.3 | 門口有人時拒絕關門 |
| 寶箱、祭壇、取心、離開（E） | 0.6 | — |

**空中擊破**：箭或石頭在空中打中飛行中的煙霧瓶，瓶子在那個位置破裂，效果與落地相同（不是必要操作）。

### 敵人

| 敵人 | 看點 | 對策 |
|---|---|---|
| 盾衛（寬肩、圓盾、闊劍） | 舉劍發光 → 揮擊方向鎖定（地上出現橘色扇形）；看到遠程武器會舉盾前進 | 側移或後退；正面盾牌擋箭，舉盾時連頭也擋——等它舉劍、收招時射頭，或繞背 |
| 弩手（兜帽、長弩） | 紅色瞄準線，變亮代表已鎖定 | 側移閃弩矢；任何命中都會打斷瞄準 |
| 突進者（角盔、衝撞盾） | 低頭蓄勢，地上出現橘色衝鋒線；角盔擋住正面的頭 | 閃開讓它撞牆：暈眩 1.5 秒、頭露出來、受傷 ×2 |

敵人頭上：**Zz** 睡眠、**?** 起疑（圈填滿就會發現你）、**!** 發現你。敵人會開門，但要停下來花時間。

### 職業（開始前在主選單選擇）

兩個職業有**明確的起始武器＋一條職業規則**。主選單選中職業就會展開完整說明（起始裝備、職業規則、擅長與弱點、代表性的一刻），暫停選單也有「職業說明」。詳細規則與平衡模擬見 [`docs/classes.md`](docs/classes.md)。

| 職業 | 承諾 | 起始裝備 | 職業規則 |
|---|---|---|---|
| **戰士** | 敵人已經出手了，我走進他的攻擊節奏裡。 | 1 長劍、2 投擲石 ×3、右鍵／F 臂盾 | **反擊斬**：敵人攻擊鎖定、就在眼前時揮劍，更快出手並打斷它。**擊開**弩矢。**盾推**：擋下正面攻擊、把敵人推退 2 m——撞牆失衡、撞同伴踉蹌、推上陷阱、推進衝鋒線。 |
| **獵手** | 我讓敵人的時間慢下來、停下來。 | 1 獵刀、2 獵弓（8 支箭）、3 藥劑箭（麻痺 2、冰寒 2） | **麻痺箭**：敵人的時間軸暫停 1.5 秒。**冰寒箭**：4 秒內變成半速。**獵人之眼**：空中煙霧瓶的提前量標記與落點圈（敵人沒有標記）。 |

- 準星下的提示（金色「反擊」、「盾推」，青綠「放箭」）與模擬用同一個判定：**出現就代表現在按下去有效**。
- 地上的彈藥袋依職業變成投擲石或箭，同一個種子兩個職業的關卡相同；結算畫面可以「換成另一個職業（同種子）」重打。
- 慢動作下瞄準本身沒有難度，所以遠程傷害改成**看時機的窗口**：盾衛看到遠程武器會舉盾前進，突進者的角盔擋頭（見 `docs/classes.md` 的平衡模擬）。

### 刻印（兩座祭壇、各二選一，本局有效）

穿甲（箭與投擲石穿透 1 名敵人）、疾刃（近戰行動時間 ×0.7）、影行（被發現所需時間 +60%）、堅韌（最大生命 +4 並回復 4）。說明文字由參數自動生成，並有測試確認效果一致。

### 操作

| 按鍵 | 功能 |
|---|---|
| WASD | 移動 |
| 滑鼠 | 觀察／瞄準 |
| 左鍵 | 使用目前武器（按住可連續） |
| 1 / 2 / 3 | 切換武器（依職業；不會取消進行中的行動）；獵手再按一次 3 切換麻痺／冰寒 |
| 右鍵／F | 臂盾・盾推（戰士；滑鼠無法鎖定時右鍵是拖曳轉視角，用 F） |
| Q | 投煙霧瓶 |
| E | 互動（門、寶箱、祭壇、往下的階梯、沉眠之心） |
| H | 喝藥 |
| 空白（按住） | 等待：讓時間正常流動 |
| Tab 或 M | 地圖（世界暫停） |
| Esc | 暫停 |
| 右鍵拖曳／方向鍵 | 無法鎖定滑鼠時（例如受限 iframe）的備用轉視角 |

按鍵以實體鍵位判斷，開著中文輸入法也能操作。

### 種子與地城

- 主選單可輸入種子；留空則隨機產生 6 字元種子。結算畫面可「同種子再試」或換新種子。
- 同一個種子會重建完全相同的初始地城與內容。
- 地城由 **2 個手工拓撲模板**（「環形中庭」有可繞行的環線；「分岔長廊」有危險支線與只能從內側拉開門閂的捷徑）加上鏡像，再從 **13 個手工設計的房間佈局**（另有 2 個練習場佈局）中挑選組合；敵人位置與配置是設計好的，依房間深度增減。這是「模板＋組合」，不是任意程序生成。
- 生成器保證：入口房沒有敵人、出生點附近看不到敵人、不經過陷阱與單向門也能抵達沉眠之心、所有寶箱與祭壇可達（以角色半徑擴張後的導航格檢查）。

### 操作練習

主選單「操作練習」：一個固定的小場地，使用與正式冒險相同的系統，有睡著的盾衛（練背刺）、巡邏盾衛、高台弩手、突進者與踏板陷阱；補給台（E）可補滿物資，暫停選單可重置。

## 測試

```bash
npm run typecheck   # TypeScript strict
npm run lint        # ESLint
npm test            # Vitest：時間規則、戰鬥、空爆、感知、AI、生成、完整流程、職業、平衡模擬
npm run build
```

瀏覽器端腳本（需先 `npm run dev` 或 `npm run preview`，並設定 `BASE_URL`，預設 `http://127.0.0.1:5173/`）：

```bash
node e2e/browser.mjs      # 主選單、localStorage 封鎖、失焦／分頁／Esc 暫停、縮放、受限 iframe、觸控提示、連續重開不殘留
node e2e/airburst.mjs     # 練習場：以正常動作鏈（Q 投瓶 → 3 → 瞄準 → 左鍵）空中擊破煙霧瓶
node e2e/retry.mjs        # 死亡 → 結算 → 同種子重試（佈局相同）→ 換職業同種子 → 新種子（佈局不同）
node e2e/floors.mjs       # 樓層：第 1 → 4 層、存檔後重新整理再繼續、取得沉眠之心通關、清除存檔
node e2e/classes.mjs      # 職業：選擇、說明、工具列；戰士反擊斬、盾推撞牆、擊開；獵手獵人之眼空爆、麻痺箭、冰寒箭（練習場）
node e2e/playthrough.mjs RUN1   # 以正常鍵鼠操作嘗試完成一整局
```

自動化腳本使用正常操作輸入（WASD、方向鍵轉向、滑鼠左鍵、E/Q/H/空白），但會透過開發模式讀取狀態來決定路線與瞄準，屬於「狀態讀取輔助」，不等同真人操作。

### 開發模式

網址加上 `?dev=1` 會掛上 `window.__sd`：讀取時間、玩家、敵人、投射物、煙霧、種子與關鍵事件（`state()`、`level()`、`events()`、`renderInfo()`、`loops()` 等）。`__sd.debug.*` 是狀態注入（傳送、設定視角、設定生命），只用於定位問題。正式遊玩不會顯示任何作弊功能。

`?gfx=low` 關閉抗鋸齒並降低解析度，用於無 GPU 的自動化環境。

  - 時機關鍵的點擊以 DOM 滑鼠事件送出，走的是同一個輸入處理流程。原因是實測這個環境裡自動化工具的滑鼠要 0.6–1.4 秒才送達頁面。
  - 射擊場的兩項檢查會先重置練習場，再以**狀態注入**把玩家擺到站位；之後的動作都是正常輸入。
- 用 `run-all.mjs` 一次跑完全部腳本時，出現過兩次瀏覽器分頁卡住（renderer 記憶體 10 GB 以上），分別卡在 retry 與 airburst。單獨執行都無法重現（airburst 連跑 3 次、retry、classes 都正常，renderer 約 0.3–0.4 GB）。目前判斷是環境問題，但沒有找到確定原因。

## 已知限制

- 職業（第三輪）：兩個職業的手感、數值、是否形成不同戰術，都還沒經過真人試玩；平衡模擬只用寫死打法的機器人。試玩重點見 [`docs/classes.md`](docs/classes.md)。垂直切片的差距與路線見 [`docs/vertical-slice.md`](docs/vertical-slice.md)。

- 這是原型：數值（慢動作 0.1、行動時間、敵人強度、甦醒強度）都是第一版，尚未經過人工試玩調整。
- 4 層地城共用 2 個拓撲模板、13 個房間佈局；重玩變化來自組合與鏡像。第 4 層的「首領」只是守在沉眠之心旁的一般敵人。
- 沒有手機觸控操作與手把支援（觸控裝置會顯示提示）。
- 音效為程序合成，只做過「無錯誤、會建立音訊節點」的檢查，未經人耳調整。
- 在沒有 GPU 的環境（軟體渲染）幀率很低；一般桌面 GPU 的實際幀率尚未量測。
- `vitest` 3.x 仍有一則中度安全公告（測試工具的 mock 重新導向功能，本專案未使用、不影響打包結果）。
