# 開發者快速 Boss 測試

入口：`/?dev=1&boss=1`。只加 `?dev=1` 時，主選單也有「開發者：快速測 Boss」。一般網址不顯示這個入口；這是本機遊戲的 opt-in 開發工具，不是需要帳號權限的保密功能。

## 怎麼用

1. 選戰士或獵手，選測試配裝，按「進入第五層 Boss」
2. 鍵鼠按 Esc；手機點既有「暫停」。選「立即重打 Boss（同配裝）」、「換成另一職業並重打 Boss」或「調整測試配裝」
3. 死亡或取得沉眠之心後保留結算，不自動重開，可比較時間、承傷、命中與道具消耗
4. 返回主選單後，原本的「繼續」仍可載入正式冒險

## 固定測試條件

種子固定 `TRIAL-WARDEN`，使用既有 `createTrialWorld('heart-warden')`，場地／出生點／80 HP 守心者／階段與招式／心臟解鎖流程完全沿用實際第五層。

- 預設「職業初始裝備」：Lv1、10 HP、布衣 +0、長劍或獵刀 +0、獵弓 +0；無天賦、無背包物品。戰士石頭 3；獵手普通箭 8、麻痺／冰寒箭各 2；各有煙霧 1。知識沿用原職業
- 「Lv5・四張強化測試配裝」：70 XP、18 HP，刻意不選天賦以隔離裝備條件。兩張強化給戰士長劍或獵手弓（+2）；另兩張給皮甲（+2，減傷 3）。獵刀仍 +0；彈藥與煙霧沿用初始量。另給已知治療 2 瓶
- 後者是明示的固定測試配裝，不代表一般玩家抵達首領時的典型等級、天賦、存量或難度
- 畫面列出實際生成的配裝／HP／消耗品，遊戲中顯示開發者測試徽記，暫停可再看起始配裝
- 飢餓從 0 起算，原本開戰後暫停飢餓的規則保留。有限彈藥、治療飲用時間、職業知識、背包、反擊新按鍵要求等規則不變
- 沒有無敵、戰中補滿、免費升級、Boss 調弱或新的 debug 注入 API。治療／彈藥只有重打或換職業時還原

## 隔離與重打

開發者測試不建立 `RunState`。從深層連結進入時，正式 `superdungeon.run.v1` 在測試模式中不被讀取、寫入或刪除；Continue、一般開始／新種子與樓層存檔路徑有防護。離開測試、返回主選單後才重新讀取正式存檔。一般畫質／音量／觸控設定仍為共用設定。

每次重打、換職業或配裝都建立全新 World 與場景；恢復生命、位置、知識與初始物資，清除行動、敵人階段、穩勢、追斬、投射物、地面效果、飢餓／世界計時、統計與除錯事件。輸入清空，單一主迴圈沿用。過期的載入回呼／滑鼠鎖定回覆不能把舊世界帶回選單。

正式冒險與原有四場試煉不採用這些配裝。原有練習死亡後自動重開仍保留。

- `tests/bossTestApp.test.ts`：以 CPU DOM／輸入／renderer stubs 配合真實 World；正式存檔零存取、載入／連點／退出競態、遲來的 pointer-lock、手機入口、重打／換職業／結果／離開後 Continue、原練習自動重開
- `e2e/boss-test.mjs`：真實按鈕與鍵盤路徑及唯讀開發快照。用於有可執行瀏覽器的環境，不等於人類打贏 Boss 的證據
- 本次 typecheck、lint、1128 項 Vitest（59 檔）、production build、diff whitespace 檢查通過；獨立交叉檢查另跑 36 項相關測試通過
- 實際 dot 雲端瀏覽器嘗試現有正式站時，WebGL 初始化在更動前就失敗：`GL_RENDERER = Disabled`、`Error creating WebGL context`。因此沒有完成 GPU、音效、UI 操作或手機真機驗收；未繞過限制、未使用使用者電腦
- 新增的 Playwright E2E 腳本尚未執行。CPU DOM／模擬通過不等於瀏覽器或真人驗收
