# 單件鑑定卷軸 v1

2026-10-02。接在守心者壓力修正後，獨立加入一種已有明確名稱的工具卷軸。

## 玩家規則

- 一張鑑定卷軸只讓玩家選 **一疊背包內的未知藥水或未知卷軸**。選到的物品完整保留；不喝藥、不讀目標卷軸、不觸發其效果。
- 沿用整局「種類知識」：辨識這一疊後，同種類的其他堆疊、地上物與以後拿到的物品也認得。沒有選到的其他種類維持未知。裝備原本已知，不列入選擇。
- 鑑定卷軸自身與強化卷軸一樣 **始終已知**。不用先鑑定鑑定卷軸，也不加入未知卷軸的外觀洗牌。
- 背包沒有有效目標時，「讀」會停用並說明原因；模擬層仍重新檢查，拒絕時不扣卷軸、不開始閱讀動作。
- 從背包按「讀」後，開始時預扣一張，正常花 **0.6 世界秒**（已有迅捷效果時沿用半時長規則）。這段仍會增加飢餓，敵人仍可攻擊；麻痺中斷或死亡不退款、不給知識。
- 讀完才開選單。選單期間世界時間、移動、攻擊與飢餓全部暫停。點選、數字 1–9／0（第十個）、Tab／Enter 都可操作；手機直接點選。取消按鈕與 Esc 只取消鑑定，不取消天賦或強化。
- 取消／完成時已無目標，退回該張尚未使用的預扣卷軸。閱讀時間不退。背包若已滿，實體卷軸安全留在腳邊；不超過每疊 99，不生成額外副本。
- 鑑定到治療藥水後，H 可使用它；鑑定到冰霜／麻痺藥水後，擁有藥劑師的獵手可以使用既有配方。鑑定本身不補血、不送箭、不增加物品數量。

## 供給與舊版相容

- `IDENTIFY.guaranteedPerFloor` 為 `[1, 0, 0, 0, 0]`，普通練習保底 0。第一探索層主線有一張可達、安全的固定拾取物；不是開局免費放進背包。
- 既有隨機卷軸池加入鑑定，四類等機率。隨機抽到卷軸時，傳送／地圖／沉睡由各 1/3 改為各 1/4，鑑定為 1/4；仍只用原本一次 RNG 抽樣。藥水與裝備的抽取分支、次數不變。另量測 40 個種子 × A/B 兩模板的 80 局完整五層生成：每局固定恰一張，地面／寶箱隨機鑑定為 0–5 張、平均 1.9125 張；不含實戰敵人掉落。
- 固定補給是追加到原有佈置後，不占用舊拾取物位置，也不推移 RNG。前四層四張強化、乾糧 1/1/2/2/0、治療固定 3/2/2/2/0 不變。沒有無限補給服務。
- `ALL_SCROLLS` 仍只有傳送、地圖、沉睡；舊卷軸圖樣與 v1/v2 六種藥水外觀映射逐一不變。同種子兩職業的世界、物資一致，只保留既有起始知識差別。
- 存檔只新增合法 ItemId `scroll:identify`，不改版本。現行與支援的舊存檔仍能讀；跨層保留卷軸、知識與原物品數量。仍是每層開頭存檔，不新增中途存檔或選單保留機制。

## 實作安全

- 目標選項持有實際 `InvItem` 物件參照，而非只記背包索引。排序仍指向原物品；替換、移除、已知或空堆疊的過時選項不能意外辨識別的東西，會重建有效選單。
- 預扣所有權與 `settled` 終止標記確保取消、重複點擊、重複呼叫、已完成選單重入都最多結算一次。
- 等在天賦後面的鑑定選單，出現前重新檢查有效目標；取消或失效仍正確接續下一個待選天賦。
- 獨立審查找到並修復「讀完與致命攻擊發生於同一子步，死亡後仍開選單而卡住結算」：只有存活且沒有結局的目前世界能開／操作選單。舊選單回呼與按住 Enter／Space 的自動重複不會偷選下一個天賦。
- 介面卡片只輸出種子外觀、未知分類與數量；圖路徑、替代文字、ARIA、data 屬性都不藏實際效果名稱。新銀色眼形印章用原創 Blender 程序模型製作；既有 25 張 runtime WebP 位元不變。

## 驗證與人工路線

自動測試覆蓋單選、多疊同類、其他種類保持未知、目標不消耗、無目標、動作前後變動、過時索引、取消／退款／滿背包／99 上限／終止選單重入、死亡／中斷、H／藥劑師知識、30/60/120 FPS 閱讀成本、飢餓與世界暫停、種子與兩職業外觀、存檔與 UI 資訊保護。最初四個核心回歸在修改前均失敗，修改後通過。

人工檢查路線：

1. 開新局，到第一探索層主線撿鑑定卷軸，取得兩種未知物品後開背包。
2. 按讀，確認先有正常閱讀動作；選單出現後等待，確認世界與飢餓暫停。
3. 選一疊，確認其數量不變、同種類已知、另一種類仍只顯示外觀。
4. 再次讀鑑定卷軸，按取消／Esc，確認退回一張。沒有未知物品時確認不能浪費閱讀。
5. 手機橫向與窄螢幕確認圖片、長文字、最後一個選項與取消按鈕可滾動／點擊；桌面測 Tab、Enter、數字鍵，返回戰鬥沒有殘留按住攻擊或移動。
6. 獵手鑑定治療後測 H；有藥劑師時鑑定冰霜後測配方。下一層退出續玩，確認知識和剩餘物品正常。

最終 `npm run typecheck`、`npm run lint`、`npm test`、`npm run build` 與 `git diff --check` 全部通過：56 個測試檔、1087 個測試。

新增 `e2e/identify-scroll.mjs` 並加入完整瀏覽器套件，涵蓋真實讀取／選取／取消操作、鍵盤、桌面／手機版面與資訊保護。但本環境的 Chromium 在啟動時回報 `socket() failed: Operation not permitted` 並以 SIGABRT 結束，**尚未執行任何 E2E 斷言**。模擬與 DOM 單元測試不等於真機觸控／GPU 手感驗收。
