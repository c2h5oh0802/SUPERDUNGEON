# 單件鑑定卷軸 v1.1

2026-10-02。加入單件鑑定後依使用者規則修正：鑑定本身也屬未知卷軸，要先試讀才認得。

## 玩家規則

- 一張鑑定卷軸只讓玩家選 **一疊背包內的未知藥水或未知卷軸**。選到的物品完整保留；不喝藥、不讀目標卷軸、不觸發其效果。
- 沿用整局「種類知識」：辨識這一疊後，同種類的其他堆疊、地上物與以後拿到的物品也認得。沒有選到的其他種類維持未知。裝備原本已知，不列入選擇。
- 鑑定卷軸本身 **一開始未知**，與其他卷軸一樣顯示種子符文外觀。首次正常讀完才認得它，再提供一個其他未知物品的選擇；不會把同種鑑定卷軸列為自己的目標。目前戰士仍只預知治療／傳送，獵手仍只預知隱形／地圖；沒有新增起始知識或起始卷軸。強化卷軸仍固定已知。
- **已知鑑定**在沒有有效目標時，「讀」會停用並說明原因；模擬層仍重新檢查，拒絕時不扣卷軸、不開始閱讀動作。**未知鑑定**不根據隱藏效果停用，避免用介面猜答案；沒有其他未知物品也可正常試讀，完成後認得自身並消耗一張，不開空選單。
- 從背包按「讀」後，開始時預扣一張，正常花 **0.6 世界秒**（已有迅捷效果時沿用半時長規則）。這段仍會增加飢餓，敵人仍可攻擊；麻痺中斷或死亡不退款、不給知識。
- 讀完才開選單。選單期間世界時間、移動、攻擊與飢餓全部暫停。點選、數字 1–9／0（第十個）、Tab／Enter 都可操作；手機直接點選。取消按鈕與 Esc 只取消鑑定，不取消天賦或強化。
- **首次試讀已經獲得卷軸自身知識**，取消只放棄額外鑑定，不退這張卷軸；選單會明確說明。**先前已知的鑑定**在取消／完成時已無目標，才退回該張尚未使用的預扣卷軸。閱讀時間不退。背包若已滿，實體卷軸安全留在腳邊；不超過每疊 99，不生成額外副本。
- 鑑定到治療藥水後，H 可使用它；鑑定到冰霜／麻痺藥水後，擁有藥劑師的獵手可以使用既有配方。鑑定本身不補血、不送箭、不增加物品數量。

## 供給與舊版相容

- `IDENTIFY.guaranteedPerFloor` 為 `[1, 0, 0, 0, 0]`，普通練習保底 0。第一探索層主線有一張可達、安全的固定拾取物；不是開局免費放進背包。
- 既有隨機卷軸池加入鑑定，四類等機率。隨機抽到卷軸時，傳送／地圖／沉睡由各 1/3 改為各 1/4，鑑定為 1/4；仍只用原本一次 RNG 抽樣。藥水與裝備的抽取分支、次數不變。另量測 40 個種子 × A/B 兩模板的 80 局完整五層生成：每局固定恰一張，地面／寶箱隨機鑑定為 0–5 張、平均 1.9125 張；不含實戰敵人掉落。
- 固定補給是追加到原有佈置後，不占用舊拾取物位置，也不推移 RNG。前四層四張強化、乾糧 1/1/2/2/0、治療固定 3/2/2/2/0 不變。沒有無限補給服務。
- `ALL_SCROLLS` 是傳送、地圖、沉睡、鑑定。既有四個符文排列原本只使用前三個，鑑定取第四個空缺；前三種逐一不改，沒有新增 RNG 抽樣或外觀版本。v1/v2 藥水外觀也不變。四種卷軸外觀互不相同，兩職業同種子映射一致。辨識前後圖樣不換成特殊圖示。
- 存檔仍為 v2／inventoryVersion 1，新增可選標記 `identifyKnowledgeVersion: 1`，讓新存檔能保存「已拾取但尚未讀過」的未知鑑定。未帶此標記的舊版存檔若已持有鑑定，保留之前已顯示名稱的知識；沒有持有時不憑空新增。明確存入的 known 總是保留。遷移不新增物品、不改其他知識與外觀；再次存取具冪等性。仍是每層開頭存檔，不新增中途存檔或選單保留機制。

## 實作安全

- 目標選項持有實際 `InvItem` 物件參照，而非只記背包索引。排序仍指向原物品；替換、移除、已知或空堆疊的過時選項不能意外辨識別的東西，會重建有效選單。
- 預扣所有權與 `settled` 終止標記確保取消、重複點擊、重複呼叫、已完成選單重入都最多結算一次。
- 等在天賦後面的鑑定選單，出現前重新檢查有效目標；取消或失效仍正確接續下一個待選天賦。
- 獨立審查找到並修復「讀完與致命攻擊發生於同一子步，死亡後仍開選單而卡住結算」：只有存活且沒有結局的目前世界能開／操作選單。舊選單回呼與按住 Enter／Space 的自動重複不會偷選下一個天賦。
- 介面卡片只輸出種子外觀、未知分類與數量；圖路徑、替代文字、ARIA、data 屬性都不藏實際效果名稱。未知鑑定不使用特殊名稱、顏色、圖案或停用理由。先前製作的銀色眼形 Blender 資產保留為歷史素材，但目前鑑定讀前讀後都只使用這局的符文圖。所有既有資產位元不變。

## 驗證與人工路線

自動測試覆蓋單選、多疊同類、其他種類保持未知、目標不消耗、無目標、動作前後變動、過時索引、取消／退款／滿背包／99 上限／終止選單重入、死亡／中斷、H／藥劑師知識、30/60/120 FPS 閱讀成本、飢餓與世界暫停、種子與兩職業外觀、存檔與 UI 資訊保護。初版四個核心回歸與這次六個「鑑定自身未知」回歸都先在各自舊版驗證失敗，再修到通過。新測試另檢查首次試讀／取消花費、未知無目標不洩漏、舊版持有者知識遷移、新版未知持有跨層不自動變已知。

人工檢查路線：

1. 開新局，到第一探索層主線撿卷軸，確認只顯示種子符文而非「鑑定」或銀色眼睛。取得兩種未知物品後開背包。
2. 試讀直到發現鑑定，確認先花正常閱讀時間再揭示名稱；選單出現後等待，確認世界與飢餓暫停。首次取消應消耗卷軸但保留新知識。
3. 選一疊，確認其數量不變、同種類已知、另一種類仍只顯示外觀。
4. 再次讀鑑定卷軸，按取消／Esc，確認退回一張。沒有未知物品時，已知鑑定拒絕使用，未知鑑定仍可付費試讀辨識自身。
5. 手機橫向與窄螢幕確認圖片、長文字、最後一個選項與取消按鈕可滾動／點擊；桌面測 Tab、Enter、數字鍵，返回戰鬥沒有殘留按住攻擊或移動。
6. 獵手鑑定治療後測 H；有藥劑師時鑑定冰霜後測配方。下一層退出續玩，確認知識和剩餘物品正常。
