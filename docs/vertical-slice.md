# 距離理想遊戲的差距，與垂直切片計劃

已確認的方向：
- 垂直切片範圍：**第一區 4 層＋首領層**。
- 平台：以 **Steam 桌面版**為目標，開發期維持網頁版。
- 長局系統從我們的核心推導（時間是貨幣；讀懂危險 → 一個簡單操作 → 戰場狀態明顯改變 → 即興）。《破碎的像素地牢》（SPD）只作為借鑑，不照抄。

## 1. 距離理想遊戲的差距

| 領域 | 現況 | 理想 | 差距 |
|---|---|---|---|
| 結構 | 4 層逐層往下、每層存檔；首領只是暫代 | 逐層往下，區域與首領 | 中 |
| 戰鬥核心 | 時間規則、讀招、3 種敵人、潛行、兩個職業（起始武器＋職業規則）、敵人弱點窗口 | 同樣的核心，更多敵人與互動 | 中：目前最成熟 |
| 長局壓力 | 沒有 | 從核心推導的壓力（地城甦醒度） | 中 |
| 物品 | 箭、石、瓶、藥、藥劑箭的數量；4 個刻印 | 會改變時間軸的裝備、附魔、藥劑與投擲物 | **大** |
| 成長 | 刻印二選一 | 深化職業規則的成長 | **大** |

## 2. SPD 的強化機制，哪些適合我們

| SPD 機制 | 放進我們的遊戲 | 適合度 | 狀態 |
|---|---|---|---|
| 塗毒飛鏢 | 藥劑箭：麻痺＝時間軸暫停、冰寒＝變慢 | 高 | **已做**（獵手） |
| 敏銳感官 | 聽得出牆後敵人的位置與攻擊階段 | 中高 | 獵手成長候選 |
| 狙擊手標記 | 命中後標記，對標記目標的下一發特別快 | 中 | 獵手成長候選 |
| 後續打擊 | 射中後近身補刀加倍 | 中低 | 只是數值，不採用 |
| 靈弓強化 | 輕箭快射 vs 重箭慢射 | 中 | 裝備系統 |
| 武器附魔 | 命中時的狀態改變（擊退、冰寒、燃燒） | 高 | 物品系統 |
| 格鬥家連擊 | 反擊成功累積連擊，強化盾推 | 中 | 戰士成長候選 |
| 守林人（草叢、種子） | 需要植被地形 | 低 | 不做 |

## 3. 長局系統（第一區）

| 系統 | 設計 | 借鑑與理由 |
|---|---|---|
| **地城甦醒度** | 世界時間與噪音累積；到門檻時，睡著的敵人醒來、巡邏變多 | 取代 SPD 的飢餓；拖延、等待、打得吵都有長期代價，延續「沉眠之心」主題。平衡模擬顯示獵手打多個盾衛要花很多世界時間，這正好由甦醒度收費 |
| **裝備＝時間軸的取捨** | 武器節奏不同（重武器準備長、失衡大；輕武器收招快）；護甲影響移動的世界時間成本 | 讓裝備直接作用在時間規則上 |
| **附魔＝命中時的狀態改變** | 擊退、冰寒、燃燒 | SPD 的武器附魔 |
| **藥草與藥劑箭** | 地城裡採到的藥草，用來補充或製作藥劑箭 | SPD 的種子與塗毒飛鏢 |
| **投擲物** | 煙霧、火、冰、噪音，都能空爆 | 延伸現有的空爆與獵人之眼 |
| **職業成長** | 候選：戰士的連擊；獵手的狙擊標記與敏銳感官 | 只選會增加狀態改變的 |
| **首領** | 多條時間軸同時進行，逼玩家組合職業動作 | 核心循環的最高強度 |

刻意**不做**：未鑑定、力量需求、照搬 SPD 的天賦樹。之後試玩證明需要，再從核心推導。

## 4. 垂直切片的完成標準

- 一局從第 1 層到首領層，約 30–45 分鐘；死亡進結算，同種子可以重試或換職業。
- 兩個職業完整：起始裝備、職業規則、第一層成長。
- 甦醒度壓力；物品約 12–16 種；第一區敵人 5–6 種（含菁英）＋首領；房間約 25 個。
- 每層開頭自動存檔、可續玩。
- 第一區的美術、音樂、音效、介面達到最終品質；基本無障礙選項；真實 GPU 1080p 60 fps。
- 至少 10 場真人試玩，搭配遙測。

   - → **功能完整切片**（美術仍是暫代）。

9. **M9 技術**（中）：存檔完整化、真實 GPU 效能、桌面打包評估、錯誤回報。

## 7. 主要風險

- **獵手在慢動作下太強**：瞄準本身不會有難度，這是刻意的；難度必須來自敵人的窗口、時間成本、箭數與多重威脅。平衡模擬是第一道檢查，真人試玩是最終判斷（見 `docs/classes.md`）。
- **盾推太穩**：戰士可能只用盾推、不再冒險反擊。限制手段：暈眩只給反擊斬。
- **長局疲勞**、**範圍膨脹**、**美術產能**：守住每個里程碑的驗收標準。
